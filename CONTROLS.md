# Controls

**Azeroth Survivors** — top-down, one hand on WASD, the other on the wheel.

| When | Key / Input | Action |
|---|---|---|
| Menu | Click a class | select class (preview hero) |
| Menu | **Enter** (or click the button) | start the run |
| Playing | **W / S / A / D** or **arrow keys** | move the hero |
| Playing | **Space** | jump |
| Playing | **mouse wheel** | zoom camera (16–70 yd) |
| Playing | **Esc** | pause |
| Playing | — | abilities cast themselves (no aim) |
| Level up | **1 / 2 / 3** (or click a card) | pick an upgrade |
| Paused | **Esc** | resume |
| Game over | **Enter** | back to the menu |
| Any | minimap **+ / −** / minimize | minimap zoom / collapse |

The camera is a fixed-angle top-down chase cam — it follows the hero but never
rotates. In the menu it slowly orbits the preview hero.
